# 星桥社区图书馆借阅规则

以下为演示用虚构资料，不能作为真实机构的规定。读者在馆内可通过服务台、目录检索设备和个人中心查询借阅信息。自助设备的可办理事项以屏幕提示为准，无法确认时应保留借阅凭证并向工作人员咨询。馆内不同区域的开放情况可能随活动安排调整，临时公告优先于本文件中的一般说明。

星桥社区图书馆周一至周五 9:00 至 20:00 开放，周六和周日 10:00 至 17:00 开放，法定节假日另行公告。读者可在开放时间内使用阅览区、自助检索机和服务台。闭馆前十五分钟，工作人员会提醒读者整理物品并办理离馆；自助还书设备是否开放以现场提示为准。普通读者的借阅数量按个人账户统一计算，不因从不同书架取书而增加。部分参考资料只供馆内阅览，具体可借状态以系统显示为准。

馆藏目录按主题、作者和索书号组织，读者可以先在检索设备中确认资料位置，再前往对应区域查找。部分书籍会因修复、盘点或读者阅览暂时不在架上，目录状态可能需要短时间更新。遇到同名书籍时应核对作者和版本信息，不能仅凭封面判断是否为预约的那一本。阅览区内的资料请放回指定书车，不要自行改变书架分类。

普通读者一次最多借阅五本纸质图书，借期二十八天。借期内可通过读者中心续借一次，续借十四天；已被其他读者预约的图书不可续借。续借成功后应在个人中心确认新的到期日，不能续借的图书需按原到期日归还。馆藏状态以系统记录为准，遇到页面信息与书籍标签不一致时，可以联系服务台核对。

逾期图书每天每册收取 0.20 元滞纳金，同一本书的滞纳金累计不超过十元。儿童绘本不收取滞纳金，但仍应按期归还。系统按自然日计算逾期时间，归还或成功续借后停止累计。账户存在逾期记录时，部分借阅服务可能暂时受限；读者可在个人中心查询记录或联系服务台核对。已被其他读者预约的图书不能通过延长借期来规避归还期限。

个人中心会展示当前借阅、历史记录和待处理提醒。读者应确认账户联系方式可以接收通知，但未收到提醒不会改变图书的系统到期日。若借阅记录出现重复或归还状态延迟，可先保存书名、时间和服务台凭证，再向工作人员反馈。图书馆不会要求读者通过邮件提供密码或支付验证码。

读者证首次办理免费，需要携带有效身份证件；遗失后补办需要支付五元工本费。挂失期间不能使用借阅服务。读者证仅供本人使用，不可借给他人办理借阅。若姓名或证件信息发生变化，可携带有效证件到服务台更新。遗失后应尽快申请挂失，挂失期间工作人员可以协助查询账户，但借阅与续借功能不可使用。

自习室座位可提前三天预约，每人每天最多预约四小时。迟到超过十五分钟且未签到，预约将自动取消。预约成功后应按页面提示完成签到，离开时及时释放座位供其他读者使用。预约记录可以在个人中心查看；如果临时无法到场，建议主动取消，避免影响后续预约。

自习区域需要保持安静，电话和线上会议请移步至指定区域。座位上不要长时间放置私人物品占位，离开时带走垃圾并关闭个人设备。预约系统显示的座位号是当日使用依据，现场若发现座位设备异常，可联系工作人员登记，不要自行拆卸桌面电源或移动公共设备。

电子书可同时借阅三本，单次借期十四天，到期自动归还。下载的离线内容会在借期结束后失效。电子资源使用个人账户授权，不计入纸质图书借阅数量。离线文件不能在授权期限结束后继续访问，重新借阅时请使用官方目录入口。设备兼容性问题可向服务台咨询，但工作人员无法延长电子书授权期限。

图书损坏或丢失时，读者可联系服务台购买同版本图书替换；无法替换时按馆方公布的赔偿规则处理。工作人员会根据馆藏记录核实图书版本和处理方式，未经确认不要自行购买替代品。读者应在发现损坏后尽快反馈，以便服务台登记情况并说明后续流程。

馆藏维护期间，部分资料会暂时标记为不可借阅；目录中显示的状态用于区分可借、馆内阅览和维护中等情况。读者提出资料缺页或装订损坏时，服务台会记录书名和索书号并安排检查。无法立即找到的图书可以提交查询请求，但查询不等同于预约成功，也不会自动延长现有借期。

还书箱位于东门外，只接收纸质图书；馆内设备和读者证不能投入还书箱。还书箱在非开放时间可接收纸质图书，系统可能在下一个工作日完成登记，读者应通过个人中心确认归还状态。馆内自助设备和读者证应交还工作人员或按现场指引处理，不能作为普通书籍投入还书箱。
