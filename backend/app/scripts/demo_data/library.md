# 星桥社区图书馆借阅规则

以下为演示用虚构资料，不能作为真实机构的规定。

星桥社区图书馆周一至周五 9:00 至 20:00 开放，周六和周日 10:00 至 17:00 开放，法定节假日另行公告。

普通读者一次最多借阅五本纸质图书，借期二十八天。借期内可通过读者中心续借一次，续借十四天；已被其他读者预约的图书不可续借。

逾期图书每天每册收取 0.20 元滞纳金，同一本书的滞纳金累计不超过十元。儿童绘本不收取滞纳金，但仍应按期归还。

读者证首次办理免费，需要携带有效身份证件；遗失后补办需要支付五元工本费。挂失期间不能使用借阅服务。

自习室座位可提前三天预约，每人每天最多预约四小时。迟到超过十五分钟且未签到，预约将自动取消。

电子书可同时借阅三本，单次借期十四天，到期自动归还。下载的离线内容会在借期结束后失效。

图书损坏或丢失时，读者可联系服务台购买同版本图书替换；无法替换时按馆方公布的赔偿规则处理。

还书箱位于东门外，只接收纸质图书；馆内设备和读者证不能投入还书箱。
