# 云舟商城配送与售后说明

以下为演示用虚构资料，不能作为真实商家的承诺。

云舟商城的标准配送覆盖中国大陆大部分地区，普通订单通常在付款后的两个工作日内发出。预售商品以商品页面标注的发货时间为准。

订单实付款满九十九元免标准运费；不足九十九元的订单收取八元标准运费。偏远地区的额外配送费用在结算页另行展示。

消费者收到商品后七天内可以申请无理由退货，商品应保持完好且不影响二次销售。定制商品、已拆封的个人卫生用品不适用无理由退货。

因商品质量问题产生的退货运费由商家承担；非质量问题的退货运费由消费者承担，双方另有约定的除外。

订单尚未出库时可在订单页面申请取消；已经出库的订单不能直接取消，可以在签收后按售后流程申请退货。

退款在退货验收通过后发起，原路退回支付账户；不同支付渠道的到账时间可能不同。

如包裹外包装明显破损，消费者应在签收前拍照并联系在线客服。在线客服服务时间为每天 9:00 至 21:00。

电子发票在订单完成后由订单页面申请，默认开具增值税普通电子发票。发票抬头和税号由用户提交并确认。
