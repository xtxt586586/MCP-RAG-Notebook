# 云舟商城配送与售后说明

以下为演示用虚构资料，不能作为真实商家的承诺。配送、付款和售后状态以订单详情页记录为准。促销、节假日和特殊商品可能适用单独说明，提交订单前应核对结算页展示的金额与预计时间。

云舟商城的标准配送覆盖中国大陆大部分地区，普通订单通常在付款后的两个工作日内发出。预售商品以商品页面标注的发货时间为准。付款成功后，订单进入仓库处理流程；节假日和促销期间可能出现延迟，页面更新后以订单详情为准。物流信息生成后可在订单页面查看，偏远地区和特殊商品的实际时效可能不同。

配送地址应在提交订单前核对，订单发出后修改地址需要联系物流或在线客服，能否拦截取决于当前运输状态。系统可能将同一订单拆分为多个包裹，物流编号和签收时间分别显示。收货人应检查商品数量和外包装，若发现运输破损，请保留包装材料并通过订单页面提交售后申请。

订单实付款满九十九元免标准运费；不足九十九元的订单收取八元标准运费。偏远地区的额外配送费用在结算页另行展示。运费门槛根据订单实付款金额判断，优惠是否计入以结算页面说明为准。特殊商品可能采用单独配送方式，购买前应查看商品页面的服务范围和费用说明。

消费者收到商品后七天内可以申请无理由退货，商品应保持完好且不影响二次销售。定制商品、已拆封的个人卫生用品不适用无理由退货。申请时需选择订单和商品并填写退货原因，售后页面会展示审核进度。商品是否符合退货条件以实际验收结果为准，附件、包装和赠品应按页面要求一并寄回。

退货寄出前请确认售后申请已通过，并使用页面提供或认可的寄回信息。包裹中不要放入与订单无关的物品，寄件后保留物流凭证以便查询。若申请状态需要补充材料，用户可以在订单售后页面提交，不要重复创建多个相同申请，以免影响审核顺序。

因商品质量问题产生的退货运费由商家承担；非质量问题的退货运费由消费者承担，双方另有约定的除外。退货申请中应尽量说明问题并提供必要的照片，客服会按订单售后流程核实。运费责任不改变商品验收要求，处理结果以订单页面记录和双方约定为准。

订单尚未出库时可在订单页面申请取消；已经出库的订单不能直接取消，可以在签收后按售后流程申请退货。提交取消申请后应等待状态更新，仓库已完成出库时无法直接拦截。取消结果和退款进度可在订单详情查看，不要重复提交多个申请。

订单状态包括待付款、处理中、已发货和已完成等阶段，不同状态允许执行的操作不同。用户提交申请后应等待平台更新结果；如果按钮仍显示处理中，不要通过其他渠道重复扣款。订单详情中的操作记录用于核对提交时间，客服会根据记录说明可采取的下一步处理方式。

退款在退货验收通过后发起，原路退回支付账户；不同支付渠道的到账时间可能不同。商家发起退款后，支付渠道仍需完成处理，到账日期以支付服务方记录为准。退款不会自动更换为其他支付方式，用户可在订单页面查看申请状态和处理说明。

如包裹外包装明显破损，消费者应在签收前拍照并联系在线客服。在线客服服务时间为每天 9:00 至 21:00。客服可以协助查询物流和售后流程，但不能改变支付渠道的处理周期。沟通时请提供订单编号和问题描述，不要提交完整银行卡号、验证码或其他敏感身份信息。

在线客服会在工作时间内按提交顺序处理咨询，复杂问题可能需要转交售后团队。消费者可以先查看帮助中心中的配送、退货和发票说明，再提供订单号和问题截图。客服不会通过非官方渠道索取账号密码，遇到可疑链接时应从商城首页重新进入订单服务页面。

电子发票在订单完成后由订单页面申请，默认开具增值税普通电子发票。发票抬头和税号由用户提交并确认。提交前请核对发票信息，开具后的修改需联系在线客服按流程办理。发票申请入口只对符合条件的已完成订单开放，发票内容应与实际交易相符。以上条款均为虚构演示内容。
