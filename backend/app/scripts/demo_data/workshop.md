# 青杉工作坊活动安排

以下为演示用虚构资料，不能作为真实活动通知。

青杉工作坊举办 Python 入门、数据可视化和团队协作三类活动，每期活动均需提前在线报名。单场活动名额为三十人，额满后进入候补名单。

报名截止时间为活动开始前二十四小时。报名者可以在活动开始前四十八小时免费取消；此后取消不退还报名费。

Python 入门活动建议携带安装有 Python 3.11 的笔记本电脑，不要求报名者具备编程经验。主办方不提供电脑租借服务。

数据可视化活动安排在每月第二个周六下午，团队协作活动安排在每月第四个周日上午。具体日期以当期报名页面为准。

工作坊地址为青杉路 18 号三层，最近的公共交通站点是青杉路站。现场没有专用停车位，建议使用公共交通。

参与者须在活动开始前十分钟到场签到。迟到者可以进入教室，但可能错过开场说明；名额不会因为迟到自动转给候补。

活动结束后三个工作日内，讲义通过报名邮箱发送。无法参加活动的报名者不会自动收到讲义。

如主办方取消活动，报名费全额退回原支付账户，并通过报名邮箱发送通知。
