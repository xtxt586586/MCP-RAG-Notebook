# 青杉工作坊活动安排

以下为演示用虚构资料，不能作为真实活动通知。每期活动的报名信息、材料和临时变更以当期活动页面为准。参与者应使用可接收邮件的联系方式，并在活动前查看主办方发送的确认通知。

青杉工作坊举办 Python 入门、数据可视化和团队协作三类活动，每期活动均需提前在线报名。单场活动名额为三十人，额满后进入候补名单。报名成功后会收到确认信息，候补者只有在获得正式名额后才可参加。工作人员按报名记录核对人数，参与者不要将确认信息转发给未报名人员。活动场次、地点和剩余名额可在报名页面查询。

活动报名按每个场次单独统计，参加过往期课程不会自动获得新场次名额。报名页面可能显示候补状态、已确认状态或报名关闭状态，参与者应以个人账户中的状态为准。活动开始前如收到主办方补充通知，请核对活动名称和日期，避免把其他场次的安排误认为本场信息。

报名截止时间为活动开始前二十四小时。报名者可以在活动开始前四十八小时免费取消；此后取消不退还报名费。取消后空出的名额按候补顺序通知，候补者需要等待主办方确认。报名页面关闭后不能新增报名，若联系方式变化应及时更新，以免错过时间、地点或活动取消通知。

取消报名后，原确认记录会更新为已取消，用户应等待系统状态刷新再离开页面。候补者收到名额通知后需在指定时间内确认，否则名额可能继续顺延。活动开始时间临近时，主办方不保证可以临时增加座位，未经确认不要直接到场占用其他参与者的位置。

Python 入门活动建议携带安装有 Python 3.11 的笔记本电脑，不要求报名者具备编程经验。主办方不提供电脑租借服务。课程从基础操作开始讲解，报名者可以提前准备问题，但无需完成预习任务。参加者应提前确认设备电量和软件版本；遇到安装问题时可在活动开始前查看页面中的准备说明。

数据可视化活动安排在每月第二个周六下午，团队协作活动安排在每月第四个周日上午。具体日期以当期报名页面为准。活动可能因讲师或场地安排调整，更新后以活动页面为准，主办方会向已报名者发送通知。报名者应在出发前重新确认日期与开始时间，不要只依赖旧的日历记录。

活动日程按本地时间展示，报名页面会列出预计时长和签到安排。课程可能包括讲解、练习和问答环节，实际顺序会根据现场情况调整。参与者可以提前准备与主题相关的问题，但应遵循讲师的现场安排，不录制其他参与者的发言或拍摄未公开的个人信息。

工作坊地址为青杉路 18 号三层，最近的公共交通站点是青杉路站。现场没有专用停车位，建议使用公共交通。进入大楼后按活动指引前往三层，不要进入未开放的办公区域。公共交通临时调整时，请预留步行时间；具体导航信息以当期活动页面提供的地址为准。

参与者须在活动开始前十分钟到场签到。迟到者可以进入教室，但可能错过开场说明；名额不会因为迟到自动转给候补。签到时工作人员会核对报名信息；遇到姓名或邮箱不一致时，可出示确认通知协助查找。为避免影响课程，请尽量在开场前完成签到并将手机调至静音。迟到不会自动取消参与资格，也不会触发候补替换。

现场签到完成后，工作人员会说明教室设备和紧急出口位置。参加者应按指引使用投影、插座和共享材料，活动结束后带走个人物品。若需要无障碍协助或有特殊设备需求，建议提前通过报名页面联系组织者，以便确认场地条件。

活动结束后三个工作日内，讲义通过报名邮箱发送。无法参加活动的报名者不会自动收到讲义。若联系方式变更，应在活动前更新报名邮箱。讲义仅发送给实际参加者，邮件未收到时可以先检查垃圾邮件，再通过报名页面联系主办方核对发送情况。

如主办方取消活动，报名费全额退回原支付账户，并通过报名邮箱发送通知。退款处理进度以支付渠道和报名页面记录为准。活动内容、签到和通知均属于虚构演示资料，不能替代主办方针对具体场次发布的正式安排。
